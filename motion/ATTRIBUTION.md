# Motion Data Attribution

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

- Original database: Carnegie Mellon University Graphics Lab Motion Capture Database
- BVH mirror/conversion: `una-dinosauria/cmu-mocap`, based on the Bruce Hahne / cgspeed conversion
- This project does not sell or redistribute the source database as a standalone motion-data product. It builds browser previews and derived runtime streams for the application.
