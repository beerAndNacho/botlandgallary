BVH → 19관절 변환기

의존성 없는 순수 파이썬 CLI가 BVH 계층을 파싱하고 순운동학으로 월드 좌표를 계산합니다. 손·발 네 점으로 압축하지 않고 골반, 척추, 가슴, 목, 머리, 무릎과 팔꿈치를 모두 보존합니다.

python tools/bvh_to_mocap.py \
  https://raw.githubusercontent.com/una-dinosauria/cmu-mocap/master/data/141/141_19.bvh \
  walk.json --target-leg 0.87 --fps 30 --yaw 180 \
  --autoloop --inplace --smoothloop 10
  • --start --dur --fps --yaw --mirror
  • --autoloop --inplace --smoothloop N
  • 머리 중심 +0.125 m, 발목 바닥 안착, 첫 골반 x·z 원점

연속 동작 규칙

  1. 경로를 쓰는 클립은 반드시 --inplace 변환본이어야 합니다.
  2. rate = 경로 속도 / mps로 맞춰 발 미끄러짐을 줄입니다.
  3. 속도 경계는 phaseAt에 위상 연속 공식을 적용합니다.
  4. yaw는 언랩한 누적 값으로 보간합니다.
  5. render(t)는 t와 고정 파라미터만 사용합니다.
phaseAtk+1 = tb − (tb − phaseAtk) · rk / rk+1
